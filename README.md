# 🔒 SANZZLUA Discord Obfuscator

Bot Discord untuk melakukan obfuscation file Lua dengan tingkat keamanan tinggi (Anti-AI, Anti-Tamper).

## 🚀 Setup Deployment (Railway)
1. Push semua file ini ke repository GitHub baru.
2. Buka **Railway App** (https://railway.app/).
3. Klik **New Project** -> **Deploy from GitHub repo**.
4. Pilih repository bot kamu.
5. Pergi ke tab **Variables** di Railway.
6. Tambahkan variabel baru:
   - Key: `DISCORD_TOKEN`
   - Value: `MASUKKAN_TOKEN_BOT_DISCORD_KAMU_DISINI`
7. Railway akan otomatis melakukan *build* dan bot akan langsung online.
